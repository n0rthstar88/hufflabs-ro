Setup guide

Everything you need to go from your invite to playing. You'll need the invite message you were sent: it has your Tailscale share link and your invite code.

1 · Connect to the server

The game server is private. You reach it through Tailscale, a free app that stays in the background.

  1. Install Tailscale from tailscale.com/download and sign in with any account (Google, Microsoft, GitHub…).
  2. Open the share link from your invite message and accept it.
  3. Keep Tailscale connected whenever you play. On Windows it's the icon near the clock.

If this page opened, you're already connected.

2 · Install the game

Windows

  1. Download HuffLabsRO-Setup.exe and run it.
  2. If Windows says “Windows protected your PC”, click More info, then Run anyway. Click Yes when it asks for permission.
  3. Keep the suggested folder (C:\Games\HuffLabsRO). The game downloads once, about 4 GB. If it stops, run the setup again and it carries on where it left off.
  4. When it finishes there's a HuffLabs RO shortcut on your desktop and in the Start menu.

Linux

  1. Install umu-launcher from your distro's packages.
  2. Download hufflabs-ro-install.sh, then run bash ~/Downloads/hufflabs-ro-install.sh in a terminal.
  3. Start HuffLabs RO from your app launcher.

3 · Create your account

On the main page, fill in Create your account with the invite code from your message. The code works once.

  • Username: 4–23 letters, numbers or _.
  • Password: 8–23 characters.

4 · Play

  1. Open HuffLabs RO. The launcher checks for updates, then starts the game. The very first start takes about a minute.
  2. Log in with the username and password you just made.
  3. Your first character asks you to pick a pace: Standard or Fast (15x XP). It's permanent for that character, so pick “Decide later” if you're not sure.

Good to know in game

  • Type @menu, or click the @ button in the row under your HP/SP bars, for every command. You can use them straight from the menu, for example to jump to any town.
  • Every town has a free Healer and a Warper.
  • Monsters drop HuffLabs Coins. Spend them at the coin shop in Prontera.
  • Updates install themselves: just open the game the usual way.

If something goes wrong

  • Can't connect or log in: check Tailscale is connected and that you accepted the share link. Then try again.
  • “There was an error when loading the data account settings”: harmless. Click OK and carry on.
  • The setup or launcher is blocked by your antivirus: allow it. The files come from this site only.
  • Anything else: send a screenshot to whoever invited you.
